# Backend

Server-side API built with NestJS and TypeScript.

## Setup & Running

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run start:dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Run production build:**
   ```bash
   npm run start:prod
   ```

## Common Scripts

- `npm run start:dev` - Start server in watch/development mode
- `npm run build` - Compile TypeScript to `dist/`
- `npm run start:prod` - Run compiled server
- `npm test` - Run tests
- `npm run lint` - Run linter
